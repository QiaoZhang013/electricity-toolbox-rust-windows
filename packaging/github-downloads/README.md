# 电力工具箱 · Windows 版

## 安装与使用

### Windows x64（v0.1.25）

已有 v0.1.25 `.exe` 安装包的用户可双击安装，完成后打开“电力工具箱”。安装包已内置运行环境，无需单独安装 Python、Rust 或 Node.js。

首次使用时，按工具页面提示选择业务文件，并填写业务网站账号。

## 后续更新

从旧 GitHub 账号下载安装的版本，需先手动安装一次 v0.1.25 迁移版，以切换后续更新地址。安装会保留配置和业务数据。

之后在工具箱托盘菜单点击“检查更新”，按提示下载并安装新版。更新会保留配置和数据。

[查看版本与更新说明](https://github.com/QiaoZhang013/electricity-toolbox-rust-windows/releases/latest)
