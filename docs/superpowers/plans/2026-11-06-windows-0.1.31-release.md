## Boundaries and failure handling

All destructive cleanup and uninstall acceptance is restricted to named test directories under `D:/electricity-toolbox-build`. Preserve actual private files in ignored backups, exclude live browser profiles from byte-equality claims, and close the real app only through its own normal `--quit` interface. Do not continue if an active task blocks shutdown. Do not use the actual installation as a patch output or overwrite any published version.

Only Windows is available here. macOS/Windows 10 actual operation and real external business write workflows cannot be claimed verified. Keep shared report source portable; do not publish a fabricated Mac installer or mix Windows and macOS manifests.
