# 下载首页与源码分支整理

用户已选择：首页只保留安装包下载入口，源码保留在开发分支。

## 设计与边界

考虑了仅整理 Releases、下载首页与源码分支分离、删除源码和历史发行三种方式。用户选定第二种：`main` 是下载页，`development` 维护完整源码；保留现有正式安装包、摘要、标签和提交历史，保持 Windows 更新地址不变。

下载页提供当前正式 Windows x64 安装包直链、最新版入口和简短安装说明。开发文档、脚本、样例资产及业务程序全部保留在 `development`。为保留 GitHub 手动构建功能，下载分支额外保留三个轻量 Actions 入口，调用开发分支的现有工作流；实际源码只在开发分支维护。下载分支的 .gitignore 只允许下载说明与维护入口，防止切换分支后误加入本机数据。
